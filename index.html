Как оформить индивидуальный проект

Основные правила оформления работы

Требования к оформлению

  • Шрифт — Times New Roman, 14 pt
  • Интервал — 1,5
  • Поля — 2 см со всех сторон
  • Объём — 10–15 страниц без приложений
  • Номера страниц — внизу по центру
  • Заголовки — Полужирные, с новой страницы

Титульный лист

  • Первая страница работы
  • Указывается: школа, тема, ФИО автора, класс, ФИО руководителя
  • Город и год — внизу
  • Тема пишется без слова «тема»
  • Оформляется по образцу

Содержание

  • Список всех частей работы
  • У каждой части — номер страницы
  • Разделы идут в том же порядке, что и в работе
  • Заголовки совпадают с заголовками в тексте
  • Оформляется на отдельной странице

Введение

  • Почему выбрал эту тему
  • Цель работы — одна
  • Задачи — 3–5 шагов
  • Актуальность темы
  • Объём — 1–2 страницы

Основная часть

  • Всё исследование по теме
  • Описание того, что ты делал
  • Таблицы, схемы, картинки — по необходимости
  • Каждая глава с новой страницы
  • Самый большой раздел работы

Заключение

  • Что получилось в итоге
  • Достиг ли ты цели
  • Какие выводы сделал
  • Где можно применить результат
  • Объём — 1–2 страницы

Список литературы

  • Все источники, которые использовал
  • Оформляются по порядку
  • Указывается: автор, название, год, издательство
  • Сайты — с полной ссылкой
  • Нумерация по алфавиту или по порядку упоминания

Приложения

  • Картинки, таблицы, схемы, фото продукта
  • Каждое приложение с номером: «Приложение 1»
  • Ссылка на приложение в тексте работы
  • Идут после списка литературы
  • Не входят в общий объём работы
